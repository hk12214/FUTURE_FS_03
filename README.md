# Campus Cravings Website 🍔

**A student-friendly food website for Campus Cravings at ASTU Stadium**  
Built as part of **Future Interns Task 3 – Full Stack Web Development** to provide a real-world online presence for a local business.

---

## 🎯 Project Objective
- Provide Campus Cravings with a **professional online presence**.  
- Make the **menu, contact info, and location** easily accessible.  
- Increase **customer convenience, trust, and engagement**.  
- Demonstrate real-world web development skills and portfolio-ready work.

---

## 💻 Features
- **Responsive Home Page:** Clean design with typewriter effect and key highlights.  
- **About Section:** Describes the business and unique selling points.  
- **Menu Section:** Accordion-style menu with categories:
  - Fast Food  
  - Local Meals (Amharic + English)  
  - Drinks  
  - Snacks  
- **Contact Section:** Embedded Google Map, phone, WhatsApp, email, and operating hours.  
- **Navigation:** Hamburger menu for mobile, smooth scrolling, and action buttons.  

---

## 🛠️ Technologies
- **Frontend:** HTML5, CSS3, JavaScript  
- **Effects & Interactivity:** Typewriter-effect library, accordion menus  
- **Other Tools:** Google Maps embed, VS Code, GitHub
